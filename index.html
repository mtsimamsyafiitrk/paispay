Membaca ulang seluruh kuitansi lalu membandingkannya dengan data yang tercatat, untuk menemukan pembayaran yang kuitansinya ada tapi tidak tercatat lunas.
Berguna untuk memulihkan pembayaran yang hilang karena input dari dua device saling menimpa (sebelum perbaikan sinkronisasi). Tabel kuitansi bersifat tambah-saja, jadi bukti tiap pembayaran masih utuh walau penandaan lunasnya sempat tertimpa.
Pemeriksaan hanya membaca. Pemulihan hanya menambah — tidak ada bulan yang dibatalkan dan tidak ada nominal yang diturunkan.

Tunggakan SPP Tahun Ajaran Sebelumnya
Centang bulan yang ditagih pada tahun ajaran tersebut, lalu isi nominalnya. Kolom Sudah dibayar diisi bila bulan itu sudah lunas atau baru diangsur sebagian — biarkan 0 untuk bulan yang belum dibayar sama sekali. Sisanya otomatis muncul sebagai tunggakan di menu Input Pembayaran.
Import Data Tunggakan & Riwayat Pembayaran
Format file yang didukung
1. JSON per santri — array objek berisi nama, status, kelas_terakhir, tunggakan_pangkal, tunggakan_pembangunan, dan tagihan_spp (daftar tagihan per bulan).
2. Baris per bulan (CSV / XLSX / JSON) — kolom nama_santri, tahun_ajaran, kelas, bulan (atau periode), nominal, dibayar, sisa.
Nama santri dicocokkan dengan data yang sudah ada (persis / mirip). Santri yang belum terdaftar akan ditambahkan otomatis. Bulan yang sudah dilunasi lewat aplikasi tidak akan dijadikan tunggakan lagi.

3. Execute as: Me · Who has access: Anyone
4. Klik Deploy → copy URL yang muncul → paste di atas
